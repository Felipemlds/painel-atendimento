⚙️ Configuração inicial

Para conectar ao seu arquivo do OneDrive, você precisa de um Client ID do Azure AD. Faça isso uma única vez em ~5 minutos:

  1. Acesse portal.azure.com com sua conta Ademicon
  2. Busque Registros de aplicativo → Novo registro
  3. Nome: Analistas Expansão | Tipo: Contas apenas nesta organização
  4. URI de Redirecionamento: Aplicativo de página única (SPA) → cole a URL desta página
  5. Após criar: copie o ID do aplicativo (cliente)
  6. Vá em Permissões de API → Adicionar → Microsoft Graph → Files.Read (delegada)
